# Security policy

## Supported versions

Only the newest release receives security fixes. MicMyDay updates itself, and
every fix ships as a new release, so there are no maintained older lines.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Anything older | No        |

## Reporting a vulnerability

Please report vulnerabilities privately, through the support page:

https://micmyday.com/support/

Include what you found, where in the code it lives if you know, and how to
reproduce it. Please do not open a public issue for a security problem before
it is fixed.

You will get a first reply within seven days. Once a fix has shipped, the
report and the fix are disclosed publicly.
